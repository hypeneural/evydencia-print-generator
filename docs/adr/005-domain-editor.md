# ADR-005 — Editor específico de domínio

**Status:** Aceito

## Decisão
Usar Fabric.js diretamente e reaproveitar ideias de editores open source, sem fork integral de um clone de Canva.

## Consequências
A UI expõe somente conceitos úteis: slots, overlay, pan, zoom, rotação, grupos, duplicação e publicação de template.
