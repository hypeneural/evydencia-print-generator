# ADR-006 — Contexto AntiGravity progressivo

**Status:** Aceito

## Decisão
Root `AGENTS.md` curto; regras de diretório para constraints locais; `.agents/rules` condicionais; Skills para procedimentos; custom agents especializados.

## Motivo
A documentação oficial do AntiGravity favorece progressive disclosure e atribui budgets separados a customizações. Menos contexto always-on melhora precisão e reduz duplicação.
