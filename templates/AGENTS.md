# Template Rules

- Todo template valida contra schemas/template.schema.json.
- schema_version define contrato; template_version define revisão do produto.
- draft pode ter posições pendentes; production não.
- Medidas canônicas em mm.
- IDs de slots/grupos estáveis.
- Grupos/duplicação são dados explícitos.
- Assets relativos à pasta do template.
- Overlay não contém foto de cliente.
- Alteração física de template publicado exige nova template_version + prova física.

Use /template-authoring.
