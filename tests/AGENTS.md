# Test Rules

- Nenhuma fixture com foto real.
- Golden tests usam imagens sintéticas com marcadores conhecidos.
- Não exigir byte-equality de JPEG entre plataformas.
- Cobrir EXIF 1/3/6/8.
- Cobrir Unicode, espaços, nomes longos, colisão de output, corrupção e template inválido.
- Shell/installer têm trilha Windows.
- Todo bug de geometria/render corrigido ganha teste de regressão.
